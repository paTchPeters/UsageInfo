SysInfo / Usage info - third-party software in this folder
===========================================================
Usage info 1.1.0, 2026-11-13.

SysInfo runs OpenRGB as a separate, unmodified program and talks to it over
OpenRGB's network SDK on 127.0.0.1. SysInfo itself does not contain OpenRGB code.

   https://gitlab.com/CalcProgrammer1/OpenRGB/-/tree/8e16de27858cf2be6af54a33ce003df74cb9fd3e

   server were left out: the PawnIO kernel-driver modules (*.bin), image and
   style plug-ins, and the shader compiler. RAM and some motherboard
   controllers therefore cannot be controlled: they need a kernel driver
   (SMBus/Super-IO), which is left out to avoid anti-cheat problems in games.
